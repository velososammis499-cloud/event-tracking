Auto Collected
自动采集的五类事件
接入后自动运行五个采集器，覆盖用户在页面上的核心行为。
pageview
页面浏览
自动捕获页面加载与 SPA 路由切换，记录路径、标题、来源与触发方式
click
元素点击
自动捕获按钮、链接、可交互元素的点击，记录标签、文本、ID 和 data-track
impression
元素曝光
通过 IntersectionObserver 监听标记元素可见性，记录可见比例与可见时长
form_interaction
表单交互
自动捕获表单聚焦、修改、提交，记录字段名与类型，过滤敏感字段
dwell
停留时长
精确计算页面活跃停留时间，跨标签页切换自动暂停与恢复

How It Works
三步接入，即刻生效
从零到数据可视化，最快只需要 5 分钟。
1

部署服务

克隆项目，运行 npm run setup 初始化，npm run dev 启动后端和看板

2

接入页面

在目标 HTML 中加入一行 <script> 标签，指定服务器地址和 App ID

3

查看分析

打开看板输入 App ID，实时查看用户行为数据和对话分析结果

# 克隆项目 git clone https://github.com/velososammis499-cloud/event-tracking.git cd event-tracking # 一键安装依赖 + 构建追踪器 + 初始化数据库 npm run setup # 启动服务（同时启动后端 :3001 + 看板 :5173） npm run dev
<!-- 在页面 </body> 前加入这一行 --> <script src="http://your-server:3001/sg.js" data-app-id="my-app" data-debug="true"></script> <!-- 可选：标记重点追踪元素 --> <button data-track="btn-submit">提交</button> <div data-track-impression="card-stats">统计卡片</div>
<!-- 在 index.html 的 <head> 中加入 --> <script src="http://your-server:3001/sg.js" data-app-id="my-spa-app"></script> <!-- Tracker 自动监听 history.pushState 和 popstate --> <!-- SPA 路由切换无需额外配置 -->
# 打开浏览器访问看板 http://localhost:5173 # 在 App ID 输入框填入你的 data-app-id # 点击「30天」时间范围按钮 # 数据即会展示在各分析页面中 # 或在对话分析页直接提问： "用户最常点击什么？" "从首页去了哪里？" "哪个页面停留最久？"
